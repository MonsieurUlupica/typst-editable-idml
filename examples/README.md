# Public examples

Original sources prepared for Jean Porcel’s SVG extension, under Apache-2.0.
These demonstrations contain no client material.

01-text.typ: Latin characters, accents, styles, rotation and script fallback.
02-imported-svg.typ: repeated artwork with clip path, marker, source text and PNG.
03-pages.typ: two-page export using page number templates.

Run bash scripts/export-examples.sh. Generated output/ files are reproducible
artifacts and are not committed. Install compatible fonts in SVG editor.
